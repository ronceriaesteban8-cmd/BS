Barber Style

Sistema web para la gestión y administración de una barbería, desarrollado como proyecto de software.

--Descripción

Barber Style es una aplicación web diseñada para facilitar la administración de una barbería, permitiendo organizar y gestionar información relacionada con sus servicios, citas, usuarios y contenido visual.

El proyecto busca ofrecer una herramienta sencilla para mejorar la organización y gestión de los procesos de una barbería.

--Funcionalidades

- Gestión de administradores.
- Gestión de usuarios.
- Administración de servicios.
- Gestión de citas.
- Visualización de galería.
- Sección de comentarios.

--Tecnologías utilizadas

- PHP
- MySQL / MariaDB
- HTML
- CSS
- JavaScript
- XAMPP

--Instalación y ejecución

1. Instalar [XAMPP](https://www.apachefriends.org/es/index.html).
2. Copiar la carpeta `BS` dentro de `C:\xampp\htdocs`.
3. Iniciar Apache y MySQL desde XAMPP.
4. Abrir phpMyAdmin desde `http://localhost/phpmyadmin`.
5. Crear una base de datos llamada `bd_barberstyle`.
6. Importar el archivo SQL de la base de datos.
7. Abrir el navegador y acceder a:

   `http://localhost/BS/`

--Base de datos

El proyecto utiliza MySQL/MariaDB para almacenar la información de la aplicación.
